# Parvus RGB

macOS lighting control for the Rampage Parvus (EVision chip, USB 320F:5055): built-in effects, colour, brightness, speed, direction, lights off while the Mac sleeps.

The EVision lighting protocol is as documented by [OpenRGB](https://gitlab.com/CalcProgrammer1/OpenRGB)'s EVision controllers; this is an independent Swift implementation.

Log: `~/Library/Logs/Parvus/Parvus.log`. Build: `Scripts/build.sh`, or push to `main` (GitHub Actions uploads `Parvus.dmg`).
